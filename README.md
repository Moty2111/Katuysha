# 🎉 С днём рождения, Катя!

**Интерактивная поздравительная открытка** с 3D-моделями, играми, анимацией и музыкой. Полностью на ванильном HTML/CSS/JS — никаких фреймворков.

---

## 🌟 Возможности

| Страница | Описание |
|----------|----------|
| **`index.html`** | Загрузочный экран с раскрывающимся цветком |
| **`gift.html`** | Подарочная коробка с анимацией открывания |
| **`inside.html`** | Основная открытка: пожелания, игры, 3D, музыка |
| **`secret.html`** | Секретная страница с признанием |

### 🎮 Интерактив

- **3D Торт со свечой** — задуй свечу кликом (THREE.js)
- **3D Беззубик** — вращай, кликай, смотри анимацию крыльев
- **🎈 Лопни шарики** — 5 шариков с конфетти
- **🎡 Колесо желаний** — крути и узнай будущее
- **🧩 Собери сердце** — пазл из 6 кусочков
- **🎵 Музыка** — играет фоновая мелодия с визуализацией
- **✨ Конфетти** — разлетается при каждом действии

### 🎨 Визуал

- Бабочки (pure CSS), лепестки сакуры, падающие звёзды
- Плавные переходы между страницами
- Полностью адаптивный дизайн (десктоп + мобильные)
- Поддержка `prefers-reduced-motion`

---

## 🛠 Технологии

| Технология | Для чего |
|------------|----------|
| **THREE.js r128** | 3D сцены (торт, Беззубик, лес) |
| **GLTFLoader + DRACOLoader** | Загрузка сжатой 3D-модели |
| **Canvas 2D** | Колесо желаний, пазл, фон |
| **Web Animations API** | Конфетти, дым, частицы |
| **CSS3 Animations** | Бабочки, коробка, цветок, всё остальное |
| **Google Fonts** | Playfair Display + Nunito |

## 🚀 Запуск

Просто открой `index.html` в браузере.

Для локального сервера (рекомендуется для 3D):
```bash
npx serve .
# или
python -m http.server 8000
```
